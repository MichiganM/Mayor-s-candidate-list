# Этап 4: WinForms UI

Созданы LoginForm, RegisterForm, TwoFactorSetupForm, MainForm, CandidateEditForm,
ElectionApplicationContext и общие UI-компоненты Ui/Ui.cs, Ui/ServiceForm.cs.
Временная ScaffoldForm удалена. Program регистрирует формы, их фабрики и ApplicationContext в DI.

Форма входа обрабатывает четыре результата AuthService, очищает пароль после попытки,
показывает поле TOTP после подтверждения пароля и позволяет начать вход заново.
Регистрация проверяется сервисом; ошибки DataAnnotations/FluentValidation выводятся через ErrorProvider.
Настройка 2FA получает otpauth URI от сервиса, строит QR локально через QRCoder и включает
второй фактор только после подтверждения кода. QR и секрет не отправляются внешним сервисам.

MainForm показывает DataGridView с русскими подписями, совместными фильтрами, действиями CRUD,
сменой статуса, перемещением, стандартными файловыми диалогами JSON и выходом из сессии.
Для удаления и замены списка запрашивается подтверждение. Экспортирует полный список.
CandidateEditForm передаёт DTO сервису; новый Id и позиция назначаются сервисом.
Шаблон существующей записи заблокирован в редакторе. Новая/изменённая запись выделяется после сохранения.

Формы не содержат EF-запросов, PasswordHasher, TOTP-алгоритмов, правил валидации или перенумерации.
Обработчики отвечают за UI-состояние и вызовы сервисов. На время операции форма блокируется,
чтобы избежать параллельной работы с одним DbContext. При выходе DI scope уничтожается.
