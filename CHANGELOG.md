# Changelog

## 1.0.0 — 2026-11-15

- Реализована иерархия участников выборов и два шаблона кандидатов.
- Добавлены SQLite, EF Core migration InitialCreate, Repository и Unit of Work.
- Подключён ASP.NET Core Identity, регистрация, блокировка и TOTP-2FA с локальным QR-кодом.
- Реализованы CRUD, статусы, фильтры, изменение порядка и JSON-импорт/экспорт.
- Созданы WinForms-формы и DI scope пользовательского сеанса.
- Добавлены 6 модульных и 16 интеграционных тестов, GitHub Actions и инструкции для защиты.
- Обновлены тестовые пакеты для устранения уязвимых транзитивных зависимостей.

Известные ограничения: .NET 8 выбран по заданию и уже завершил поддержку;
восстановление доступа при утрате аутентификатора не реализовано. Полный ручной сценарий
с внешним приложением-аутентификатором и файловыми диалогами ещё требует проверки.
